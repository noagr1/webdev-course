שלב 0: מתכננים לפני שכותבים

מפתחים מנוסים לא מתחילים מהקוד. הם מתחילים מסקיצה. קחו דף ועט וציירו קופסאות: מה יש בדף, ומה נמצא ליד מה?

header: שם (לוגו) ‏+ ‏nav עם 3 קישוריםבשורה אחת, בשני הצדדים
section ‏"עליי": עיגול עם ראשי תיבות + כותרת וטקסטזה לצד זה
section ‏"מה אני לומדת": שלושה כרטיסיםבשורה, ועוברים שורה כשאין מקום
section ‏"צרו קשר": טקסט עם קישור למייל
footer: זכויות יוצרים

כל קופסה בסקיצה תהפוך לתגית HTML. כל מקום שבו כתוב "זה לצד זה" או "בשורה" יהפוך ל-display: flex.

שלב 1: המבנה ב-HTML

מתרגמים את הסקיצה לתגיות סמנטיות. לכל section יש id, כדי שהקישורים בתפריט יוכלו לקפוץ אליו (ראו "קישורים פנימיים" בחלק א׳). את ה-class-ים מוסיפים כבר עכשיו, כי בהם נשתמש ב-CSS.

נסו: החליפו את "דנה כהן" בשם שלכם ואת הטקסט בטקסט עליכם. מעכשיו זה הדף שלכם.

למה כל כרטיס עטוף ב-<article> ולא ב-<div>?

  • כי article מעוצב אוטומטית ככרטיס
  • כי כל כרטיס הוא יחידת תוכן שעומדת בפני עצמה, ו-article מתאר את המשמעות הזו
  • כי אסור לשים h3 בתוך div

article לא מוסיף שום עיצוב. הוא אומר לדפדפן, לקוראי מסך ולמפתחים אחרים "זו יחידה שלמה". את המראה של הכרטיס נקבע ב-CSS.

שלב 2: עיצוב בסיס

מתחילים מהכללים שחלים על כל הדף:

  • משתני צבע ב-:root, כדי שאפשר יהיה לשנות את צבעי הדף במקום אחד.
  • איפוס: box-sizing: border-box, ו-margin: 0 שמבטל את המרווחים שהדפדפן מוסיף לבד.
  • גופן, צבע רקע וגובה שורה על ה-body. הילדים יורשים אותם.
  • רוחב מקסימלי ל-main, ו-margin: 0 auto שממרכז אותו. בלי זה, במסך רחב שורות הטקסט נמתחות ולא נוח לקרוא.

שלב 3: סרגל הניווט

בסקיצה כתבנו "בשורה אחת, בשני הצדדים". בשפת Flexbox זה:

  • display: flex על ה-header: הלוגו וה-nav עומדים בשורה.
  • justify-content: space-between: הראשון (הלוגו) נדחף לימין, והאחרון (התפריט) לשמאל. זה דף בעברית, אז השורה מתחילה מימין.
  • align-items: center: שניהם ממורכזים לגובה.
  • גם ה-nav עצמו הוא flex, עם gap שיוצר רווח קבוע בין הקישורים.

נסו: מחקו את השורה justify-content: space-between; ותראו שהכול נצמד לימין. אחר כך החזירו אותה. עברו עם העכבר מעל הקישורים כדי לראות את ה-:hover.

שלב 4: אזור הפתיחה והכרטיסים

שלושה טריקים בשלב הזה:

  1. עיגול: רוחב וגובה שווים ו-border-radius: 50%. כדי שראשי התיבות יעמדו בדיוק באמצע, גם העיגול הוא קופסת flex עם justify-content: center ו-align-items: center. זה המתכון הקלאסי למרכוז.
  2. flex-shrink: 0: בלי זה, כשאין מספיק מקום, Flexbox מכווץ את העיגול והוא נהיה אליפסה.
  3. כרטיסים שעוברים שורה: flex-wrap: wrap על המיכל, ו-flex: 1 1 200px על כל כרטיס. המשמעות: "רוחב בסיס של 200px, ומותר לגדול ולהתכווץ". כשאין מקום לשלושה כרטיסים של 200px, האחרון יורד שורה, והכרטיסים בכל שורה גדלים וממלאים את הרוחב.

נסו: לחצו "⤢ הרחבה" כדי שהתוצאה תתפרס על כל הרוחב, ותראו את שלושת הכרטיסים בשורה אחת. לחצו שוב, והתוצאה תחזור לחלון הצר: הכרטיסים עוברים שורה. אחר כך מחקו את flex-wrap: wrap ובדקו מה קורה בחלון הצר.

שלב 6: מעבירים ל-VS Code

העורך באתר נועד לניסויים. פרויקט אמיתי נמצא בקבצים במחשב. כך מעבירים את הדף:

1

יוצרים תיקייה ופותחים אותה ב-VS Code

$ mkdir profile
$ cd profile
$ code .

אם הפקודה code לא מוכרת, פתחו את VS Code ובחרו בתפריט File ← Open Folder.

2

יוצרים index.html

מקלידים ! ולוחצים Tab כדי לקבל שלד. משנים ל-lang="he" dir="rtl", מוסיפים בתוך ה-head את השורה שמחברת את ה-CSS, ומדביקים את ה-HTML מהעורך לתוך ה-body:

index.html

<!DOCTYPE html>
<html lang="he" dir="rtl">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>דנה כהן | פרופיל</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <!-- כאן מדביקים את ה-HTML מהעורך: header, main, footer -->
</body>
</html>

יוצרים style.css

מדביקים לתוכו את כל ה-CSS: הבסיס משלב 2, ואחריו התוספות משלבים 3, 4 ו-5. הקובץ המלא נמצא כאן.

4

פותחים עם Live Server

לוחצים בכפתור הימני על index.html ובוחרים Open with Live Server. אם הדף מופיע בלי עיצוב, כמעט תמיד הבעיה היא ששם הקובץ ב-href של ה-link לא תואם בדיוק לשם הקובץ, או שהקובץ לא שמור באותה תיקייה.

שלב 7: שומרים ב-Git ומפרסמים

עכשיו משתמשים במה שלמדנו בחלק ג׳. מומלץ לעשות commit אחרי כל שלב. ככה ההיסטוריה מספרת את סיפור הבנייה:

$ git init
$ git add index.html
$ git commit -m "Add page structure"
$ git add style.css
$ git commit -m "Add base styles, navbar and cards"
# אחרי שמוסיפים את ה-media query:
$ git add .
$ git commit -m "Make page responsive"
# יוצרים repo ריק ב-GitHub בשם profile, ואז:
$ git branch -M main
$ git remote add origin https://github.com/USERNAME/profile.git
$ git push -u origin main

לסיום מחברים את ה-repo ל-Netlify, לפי ההוראות בחלק ג׳. מקבלים כתובת כמו https://dana-profile.netlify.app, ומעכשיו כל git push מעדכן את האתר.

סיכום שיעור 1

  • הווב: הדפדפן (לקוח) שולח בקשת HTTP לשרת ומקבל בחזרה HTML, ‏CSS ו-JS.
  • HTML בונה את המבנה. משתמשים בתגיות סמנטיות, ו-div או span רק כשאין תגית עם משמעות מתאימה.
  • CSS מעצב: בוררים, מודל הקופסה, משתנים, ‏Flexbox ו-media queries.
  • Git שומר היסטוריה (add, ‏commit, ‏push), ‏GitHub מאחסן אותה, ו-Netlify מפרסם את האתר.

בשיעור הבא: ‏JavaScript. הדף שלנו יפה, אבל הוא לא עושה כלום. בשיעור 2 נלמד לכתוב קוד שמחשב, מחליט וחוזר על פעולות.
