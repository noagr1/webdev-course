⏱️ שעתיים בכיתה 📚 6–8 שעות לימוד עצמי 🧑‍🎓 נדרש: שיעור 2

בשיעור הקודם למדנו את אבני הבניין של כל שפת תכנות. עכשיו נלמד לעבוד עם נתונים אמיתיים: רשימות של מוצרים, משתמשים ומתכונים. נשמור אותם במערכים ובאובייקטים, נעבד אותם עם map ו-filter, נציג אותם בדף, ונביא אותם מהאינטרנט.

זה השיעור האחרון לפני React. בסופו נבנה אפליקציה שלמה ב-JavaScript "רגיל" (מפתחים קוראים לזה Vanilla JavaScript, כלומר בלי ספריות). בשיעור 4 נבנה את אותה אפליקציה בדיוק ב-React, ונראה כמה עבודה React חוסכת.

מטרות השיעור

בסוף השיעור תדעו:

  • לשמור נתונים במערכים ובאובייקטים, ולעבוד עם מערך של אובייקטים
  • להשתמש ב-destructuring וב-spread (...), שמופיעים בכל קוד React
  • לעבד רשימות עם map, ‏filter, ‏find ו-reduce, בלי לשנות את המערך המקורי
  • להבין מה זה ה-DOM, ולשנות את הדף מתוך JavaScript
  • להגיב לפעולות של המשתמש: לחיצות, הקלדה ושליחת טפסים
  • להביא נתונים משרת עם fetch, ‏async ו-await, ולהציג מצב טעינה ושגיאה
  • להסביר אילו בעיות React פותרת, ולמה

מה זה "Vanilla JavaScript", ולמה לומדים את זה לפני React?

‏Vanilla JavaScript הוא JavaScript "בטעם הבסיסי": רק מה שהדפדפן נותן, בלי ספריות כמו React. כשכותבים Vanilla JavaScript לדף אינטרנט, עובדים כל הזמן עם ה-DOM: הייצוג של הדף בזיכרון, שדרכו JavaScript קוראת ומשנה את מה שמוצג על המסך.

הנה הטעימה הראשונה. לחצו על הכפתור בתוצאה. ‏JavaScript מוצאת את המספר בדף ומשנה אותו:

שימו לב לשני השלבים בקוד: קודם משנים את המשתנה, ואחר כך בעצמנו מעדכנים את הדף. כאן זה קל, כי יש מספר אחד. אבל באפליקציה אמיתית יש עשרות דברים שמשתנים: רשימות, מונים, הודעות. כל אחד מהם צריך לעדכן ידנית, ואם שוכחים אחד, הדף מציג מידע לא נכון.

🖥️ מה שרואיםה-DOM

זו בדיוק הבעיה ש-React פותרת: ב-React מתארים איך הדף צריך להיראות לפי הנתונים, ו-React מעדכנת את ה-DOM בעצמה בכל שינוי. כדי להעריך את זה, צריך קודם להרגיש את העבודה הידנית. לכן בחלק ג׳ ובפרויקט נעבוד עם ה-DOM ישירות.

מה ממשיך איתנו ל-React: כמעט כל מה שבשיעור הזה. ‏map הוא הדרך שבה React מציגה רשימות. ‏spread ו-filter הם הדרך שבה מעדכנים נתונים ב-React. ‏destructuring מופיע בכל קומפוננטה, ו-fetch עם מצבי טעינה ושגיאה חוזר בשיעור 6. מה שלא ממשיך הוא העבודה הידנית עם ה-DOM, ובשביל זה בדיוק יש React.

הכנה לשיעור

  • אין צורך להתקין שום דבר חדש.
  • בחלק ד׳ ובפרויקט מביאים נתונים מהאינטרנט (מהאתרים DummyJSON ו-JSONPlaceholder). הם חינמיים ולא דורשים הרשמה, אבל צריך חיבור לאינטרנט.
  • אם לא הגשתם את הפרויקט משיעור 2, כדאי להשלים אותו קודם. הפונקציות והלולאות משם הן הבסיס לכאן.
