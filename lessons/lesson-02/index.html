⏱️ שעתיים בכיתה 📚 5–7 שעות לימוד עצמי 🧑‍🎓 נדרש: שיעור 1

בשיעור הקודם בנינו דף שנראה טוב, אבל הוא לא עושה כלום. ‏HTML קובע מה יש בדף ו-CSS קובע איך הוא נראה. ‏JavaScript היא שפת התכנות של הווב: היא מחליטה, מחשבת וזוכרת. בשיעור הזה נלמד את היסודות שכל מתכנת צריך, בכל שפה: משתנים, טיפוסים, תנאים, לולאות ופונקציות.

‏React, שנתחיל בשיעור 4, כתובה כולה ב-JavaScript. כל מה שנלמד כאן ובשיעור הבא הוא הבסיס שבלעדיו React לא תהיה מובנת.

מטרות השיעור

בסוף השיעור תדעו:

  • להריץ JavaScript בשלוש דרכים: בקונסול של הדפדפן, מתוך דף HTML, ובעורך שבאתר
  • ליצור משתנים עם let ו-const, ולדעת מתי להשתמש בכל אחד
  • לעבוד עם מחרוזות, מספרים וערכים בוליאניים, ולהמיר ביניהם
  • לקבל החלטות בקוד עם if, ‏else ואופרטורים לוגיים
  • לחזור על פעולות עם לולאות for ו-while
  • לכתוב פונקציות שמקבלות פרמטרים ומחזירות ערך, כולל arrow functions
  • לקרוא הודעת שגיאה ולמצוא בעזרתה את הבאג

טיפ ללמידה: בתכנות לומדים בידיים. הקלידו את הדוגמאות בעצמכם במקום להעתיק, גם אם זה לוקח יותר זמן. כל טעות הקלדה שתתקנו מלמדת אתכם לקרוא שגיאות.

הכנה לשיעור

  • אין צורך להתקין שום דבר חדש. מספיקים הדפדפן, ‏VS Code ו-Git משיעור 1.
  • כדאי לוודא שהתוסף Live Server מותקן ב-VS Code. נשתמש בו בפרויקט.
  • אם לא סיימתם את דף הפרופיל משיעור 1, זה הזמן. בפרויקט של השיעור הזה נעלה קוד ל-GitHub באותה דרך.

תוכנית לשעתיים בכיתה. לרוב הסטודנטים זו היכרות ראשונה עם תכנות. עדיף להתקדם לאט ולוודא הבנה, מאשר לכסות הכול. מה שלא הספקנו נשאר לקריאה בבית, כי העמודים כתובים ללמידה עצמית.
